# Board skins

The Celestial Court is drawn in code, so a skin is colors and copy only.

1. Copy `journey-west.ts` to `<id>.ts` and set the palette, court colors and sky bands, copy and font.
2. Optional: a `night` look (palette and court) turns on the sun and moon toggle on the tool belt.
3. Add it to `SKINS` in `index.ts`. The skin picker shows once there are two.
