# Design library index

When to reach for which entry. Each folder holds a DESIGN.md with tokens (colors, type, spacing) and notes. Pick 1 to 3 that fit the job, read them, then design; mix a layout reference with a skin reference rather than cloning one brand. Brand entries come from awesome-design-md (VoltAgent, MIT); the game and pixel entries at the end were written for Switchboard.

Format: `folder`: vibe. Use it when.

For website or app UI, also browse the live sites in SOURCES.md (components, text animation, fonts, 3D and scroll, colors, sections, backgrounds, inspiration, sounds).

## Dev tools and dark product UI
- `linear.app`: near-black, one lavender accent, hairline panels. A dense dark app that should feel crafted and calm.
- `vercel`: black and white duet, mesh gradient at hero only. Developer platform pages, deploy or status UI.
- `raycast`: dark, glossy command palette, red accent. Launchers, keyboard-first menus, shortcut hints.
- `warp`: warm charcoal terminal. Terminal or agent UI that should feel warmer than pure black.
- `cursor`: warm cream editorial for a code tool. A dev tool that wants light mode and a calmer voice.
- `opencode.ai`: terminal monospace minimalism. CLI docs, TUI-flavored web pages.
- `ollama`: stark monochrome, tiny palette. Local tools, plain model pages, "nothing extra" UI.
- `voltagent`: near-black with electric green, code mockups. Agent frameworks, dark hero with code.
- `composio`: near-black, deep electric blue. Agent integration and tool catalogs.
- `resend`: black, minimal, editorial type. API products and email tools with restraint.
- `supabase`: white and near-black, emerald CTA, product mockups. Database or backend dashboards.
- `sentry`: purple midnight, lime accent, cheeky illustration. Dev tools with personality, error or alert UI.
- `posthog`: playful, hand-drawn, dense docs. Analytics with humor, long docs, internal tools.
- `hashicorp`: black ground, per-product accent colors. A suite where each product needs its own color.
- `clickhouse`: black with electric yellow, stat numbers. Performance claims, benchmark pages.
- `mongodb`: deep teal bands, green pill CTA. Dual dark hero and light docs.
- `expo`: white with sky wash. Mobile dev platform, friendly infra.
- `mintlify`: sky gradients over dense docs. Documentation sites.
- `replicate`: bold, playful model catalog. Model or template galleries.
- `together.ai`, `x.ai`, `mistral.ai`, `cohere`, `minimax`: AI lab brands. Pick by mood: together (gradient chrome), x.ai (stark black, pill outlines), mistral (sunset gradients), cohere (enterprise green-black), minimax (gradient product cards).
- `claude`: warm cream, serif display, coral CTA. Warm editorial AI product pages.
- `nvidia`: black with signature green. Hardware or GPU, high-energy dark tech.
- `elevenlabs`: off-white print-magazine calm, pastel washes. Voice or audio AI, quiet editorial.
- `runwayml`: cinematic dark, media first. Creative AI and video tools.

## Retro and game
- `nintendo-2001`: beveled console chrome, amber glow, halftone. Y2K game UI and nostalgic panels.
- `playstation`: deep blue, console store. Game storefronts and console UI.
- `dell-1996`: table-era frame, flat ribbon cards, GIF stickers. 90s web nostalgia.
- `hp`: white paper, electric blue, angular. Hardware catalogs.
- `starnet-station`: agents as sprites at desks, lit desk = live run, COMMS panel. An agent or job board that should feel alive and spatial.
- `colony-sim-rooms`: RimWorld, Prison Architect, Kairosoft rooms, floor labels, overlays. Many workers in many places, readable zoomed out.
- `tactics-hud`: Into the Breach style telegraphing, Three Reads. A HUD or side panel where the user must predict what happens next.
- `palace-vermilion`: Forbidden City palette by rank, axial courtyards, cloud and lattice motifs, Journey to the West roles. An imperial or Chinese-mythic skin, such as the Celestial Court board.

## Playful and bright
- `posthog`, `sentry`, `clay`, `miro`, `replicate`: playful dev and SaaS (see above).

## Combos that work
- Agent board with a pixel world: `starnet-station` (mechanics) + `colony-sim-rooms` (legibility) + `palace-vermilion` (skin), checked against `tactics-hud`.
- Dark dashboard: `linear.app` + `ibm` for tables.
- Warm editorial product page: `claude` or `cursor` + `oura` type.
