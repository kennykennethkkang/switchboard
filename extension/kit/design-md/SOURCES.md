# Web sources for site work

Live inspiration sites for website and app UI, grouped by the part you are building. The library's DESIGN.md entries give tokens; these give current patterns. Browse 2 to 4 that fit the part (agent-browser, snapshot -i), borrow layout, motion and type ideas, never copy assets, code or fonts without checking the license. Names without a domain: search the name. Pinterest and some paid tiers need a login; skip those rather than ask.

From Hugo Manning's reel "The best inspiration sites" (instagram.com/reel/Df--4CtAgrf). Most are free; Scrolltide and Bencho keep their best items paid.

## Components
- 21st.dev: community React and Tailwind components, also an MCP in Set up. Buttons, cards, heroes, shader bits.
- Originkit (originkit.dev): animated sections and interactions for Framer and React, MIT.
- Spell UI (spell.sh): motion-heavy React components for design engineers, shadcn registry.

## Text animation
- Kawaii: grid of named text effects (3D flip, spinning words, falling, slide in, heartbeat).
- Kinetics (Colorion): spring motion catalog, plain CSS and React, MIT.
- Animation Dictionary: names for motion effects with live demos; pair with the animation-vocabulary skill.

## Fonts
- Fontshare (fontshare.com): free commercial-use fonts (Satoshi, General Sans).
- Fonts In Use (fontsinuse.com): real type pairings seen in the wild.
- Fontesk (fontesk.com): free display fonts, check each license.

## 3D and scroll
- Scrolltide: scroll-driven landing pages, 3D scenes and shader backgrounds with prompts. Paid tier.
- GetLayers: cinematic sections, Three.js scenes, video backgrounds, has an MCP.
- MotionSites (motionsites.ai): copy-paste prompts for motion-heavy sites.

## Colors
- Coolors (coolors.co): palette generator and explorer.
- Pinterest: mood boards; search "<product> website design".

## Sections and details
- Unsection: section-first library (hero, pricing, FAQ, footer) to compare one block across many sites.
- details.so: close-ups of the small details on top sites (nav, buttons, scroll states).
- Supahero: hero section library.

## Backgrounds
- backgrounds.supply: free gradients, AI art and 4K video backgrounds.
- Gradient Lab: animated mesh and wave gradient editor with export.
- Super Visuals: background image packs.

## General inspiration
- Awwwards (awwwards.com): award-level sites; pair with the awwwards skill.
- curated.design: hand-picked sites and sections, searchable by what you are building.
- Pinterest: see Colors.

## Sounds
- UI SFX (github.com/romainsimon/uisfx): CC0 interface sounds in 12 styles, npm.
- Bencho: React blocks with synthesized interface sounds. Paid tier.
